# 北海道で化石についてよく知れる場所・博物館ガイド

北海道は中生代や新生代の地層が広く分布しており、日本における化石の宝庫として知られています。アンモナイトや恐竜、海洋爬虫類の化石などを間近で学べる、特におすすめのスポットをご紹介します。

---

## 1. 三笠市立博物館（三笠市）
* **特徴**: 日本屈指の「アンモナイトの街」として知られる三笠市にある、化石・地質専門の博物館です。
* **見どころ**: 
  * 館内には数多くのアンモナイトや多様な古生物の化石が圧巻のボリュームで展示されています。
  * 北海道で見つかったエゾミカサリュウ（首長竜の仲間）の化石など、貴重な標本が揃っています。
  * 野外の「自然公園（桂沢湖周辺など）」では、実際に化石が含まれる地層や露頭を見学できる環境が整っています。

## 2. むかわ町穂別恐竜博物館 / 穂別博物館（むかわ町）
* **特徴**: 全身骨格が国内で発見され話題となった「カムイサウルス・ジャポニクス（通称：むかわ竜）」の故郷です。
* **見どころ**:
  * 恐竜の全身骨格（実物・レプリカ）や、白亜紀の海の生物（アンモナイト、モササウルス類などの海生爬虫類）の化石が豊富に展示されています。
  * 恐竜が暮らしていた時代の北海道の自然環境や、化石発掘の歴史を分かりやすく学べます。

## 3. 北海道博物館（札幌市）
* **特徴**: 札幌市厚別区（野幌森林公園内）にある、北海道の自然・歴史・文化を総合的に学べる道立の博物館です。
* **見どころ**:
  * 北海道の成り立ちや大地の変動、太古の時代に生息していた大型哺乳類（ナウマンゾウやヤリマンマンモスなど）の化石や骨格標本が展示されています。
  * 道内の広いエリアの自然史を俯瞰して学ぶのに最適な施設です。

## 4. 北海道大学総合博物館（札幌市）
* **特徴**: 札幌市中心部の北大キャンパス内にある、入場無料のミュージアムです。
* **見どころ**:
  * 大学が長年かけて収集・研究してきた学術標本が多数収蔵されています。
  * 化石や地質に関する研究成果や、北海道特有の化石標本をアカデミックな視点でじっくり見ることができます。

* **事前の開館確認**: 施設によっては冬季休館やリニューアル、見学エリアの制限がある場合があります。お出かけ前に各公式サイトをご確認ください。
* **採集のルール**: 北海道内の多くの河川や山林では、私有地や保護地域、あるいは法律・条例で化石の勝手な採集が禁止されている場所があります。原則として「見て学ぶ（博物館）」をメインにし、ルールを守って楽しみましょう。
