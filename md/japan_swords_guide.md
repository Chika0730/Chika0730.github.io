# 日本で見ることができる刀剣ガイド

日本刀は、武器であると同時に、鉄の質感・刃文・姿の美しさを鑑賞する美術工芸品でもあります。本ガイドでは、刀剣の基本、鑑賞できる主な施設、有名な名刀、鑑賞のコツをまとめます。

> **ご注意**: 刀剣は保存上の理由から展示替えが頻繁に行われます。特定の刀を見たい場合は、訪問前に各施設の公式サイトで展示予定・開館時間・休館日をご確認ください。

---

## 1. 刀剣の基本

### 主な種類

| 種類 | 特徴 |
|---|---|
| 太刀(たち) | 刃を下に向けて腰に吊るす長めの刀。平安〜室町時代が中心 |
| 刀(かたな) | 刃を上にして腰に差す。室町後期以降に主流 |
| 脇差(わきざし) | 刀より短い副差。江戸時代は武士の携帯品 |
| 短刀(たんとう) | 約30cm以下。護身用・儀礼用など |
| 薙刀・槍 | 長柄の武器。寺社の宝物として残る例も多い |

### 時代による区分

- **古刀**(〜室町時代):備前、山城、大和、相模、美濃の「五箇伝」が有名
- **新刀**(江戸初期〜):実用と装飾性が両立した時代
- **新々刀**(江戸後期〜幕末):古刀の復興を目指した作風
- **現代刀**:現在も刀匠が制作

### 文化財の指定

美術的・歴史的に特に価値の高いものは**国宝**や**重要文化財**に指定されています。国宝の刀剣は、美術工芸品の中でも大きな割合を占めます。

## 2. 刀剣を見られる主な施設

### 東京・関東

**東京国立博物館(上野)**
- 本館に刀剣の展示コーナーがあり、国宝・重要文化財クラスの刀剣が展示替えしながら公開されます。
- 「三日月宗近」「童子切安綱」など、天下五剣に数えられる名刀を所蔵しています。
- 初めて名刀を見るなら最初の候補になる場所です。

**刀剣博物館(東京・両国)**
- 公益財団法人日本美術刀剣保存協会が運営する、刀剣専門の博物館です。
- 刀剣、刀装具、鍔などを幅広く展示し、鑑賞の基礎を学べます。

**靖国神社 遊就館(東京・九段)**
- 近代の軍刀や、昭和期に作られた刀剣(靖国刀)などを関連資料とともに展示しています。
- 近代以降の刀剣の歴史に触れられる点が特徴です。

**皇居三の丸尚蔵館(東京・皇居東御苑)**
- 皇室に伝わった美術品を所蔵しており、「大包平」「鬼丸国綱」など皇室ゆかりの名刀が公開されることがあります。
- 展示内容は企画展ごとに変わるため、事前確認が必須です。

### 中部

**関鍛冶伝承館(岐阜県関市)**
- 「刃物の街」関市にあり、美濃伝(関の孫六など)の歴史を紹介しています。
- 刀鍛冶の技を見学できる催しが行われることもあります。

**徳川美術館(愛知県名古屋市)**
- 尾張徳川家に伝来した大名道具を所蔵し、刀剣や刀装具も多数あります。
- 大名家の格式や蔵品の背景とあわせて鑑賞できます。

**熱田神宮 宝物館(愛知県名古屋市)**
- 熱田神宮は三種の神器の一つ「草薙剣」を祀る神社ですが、草薙剣そのものは非公開です。
- 宝物館では、奉納された刀剣などを見ることができます。

**佐野美術館(静岡県三島市)**
- 刀剣の展覧会を継続的に開催していることで知られる美術館です。

### 関西

**京都国立博物館(京都)**
- 国宝・重要文化財の刀剣を所蔵しています。特別展の際に刀剣が展示されることがあります。

**石上神宮(奈良県天理市)**
- 国宝「七支刀」を所蔵することで知られます。ただし通常は公開されておらず、特別な機会にのみ公開されます。

### 中国・四国・九州

**備前長船刀剣博物館(岡山県瀬戸内市)**
- 名刀の産地・備前長船にある、日本刀に特化した博物館です。
- 日本刀の鍛錬場や研ぎ師の工房見学など、制作工程に触れられる体験があります。

**厳島神社 宝物館(広島県廿日市市・宮島)**
- 神社に奉納された武具や刀剣が伝わっています。

**大山祇神社(愛媛県今治市・大三島)**
- 古来より武将の崇敬を集め、甲冑や刀剣など武具の奉納品が非常に多い神社です。
- 日本有数の武具の宝庫として知られます。

**九州国立博物館(福岡県太宰府市)**
- 特別展・企画展で刀剣を見られる機会があります。

## 3. 有名な名刀

### 天下五剣(てんがごけん)

室町時代以降、特に名刀とされた5振です。

| 名称 | 作者 | 現在の所蔵・伝来 |
|---|---|---|
| 童子切安綱(どうじぎりやすつな) | 安綱 | 東京国立博物館(国宝) |
| 三日月宗近(みかづきむねちか) | 三条宗近 | 東京国立博物館(国宝) |
| 鬼丸国綱(おにまるくにつな) | 国綱 | 皇室ゆかりの御物 |
| 大典太光世(おおでんたみつよ) | 光世 | 前田育徳会(国宝) |
| 数珠丸恒次(じゅずまるつねつぐ) | 恒次 | 兵庫県・本興寺(重要文化財) |

### その他の有名な刀

- **大包平(おおかねひら)**:「日本刀の最高傑作」と評されることもある名刀で、皇室ゆかりの国宝
- **七支刀(しちしとう)**:枝のように刃が分かれた古代の鉄剣。石上神宮に伝わる国宝
- **草薙剣(くさなぎのつるぎ)**:三種の神器の一つ。熱田神宮に祀られるが非公開

## 4. 鑑賞のポイント

1. **姿(すがた)**:全体のシルエット。反りの深さや身幅から時代を読み取れます
2. **刃文(はもん)**:焼き入れで生まれる刃の模様。直刃、乱れ刃など流派ごとの特徴があります
3. **地鉄(じがね)**:鉄の肌模様。板目、柾目、杢目などがあります
4. **切先(きっさき)**:先端部分の形と刃文の返り方
5. **茎(なかご)**:柄に収まる部分。銘や鑢目(やすりめ)が見られることがあります
6. **拵(こしらえ)と刀装具**:鍔や目貫など、金工の美も見どころです

> 刃文や地鉄は光の当たり方で見え方が大きく変わります。角度を変えながら、ゆっくり見るのがおすすめです。

---

## 5. 訪問時のマナーと準備

- 展示ケースの照明下で刃文を見るため、時間に余裕を持つこと
- 撮影の可否は施設・展示ごとに異なるので、掲示を確認すること
- 刀剣は展示替えが多いため、**見たい刀が公開中かを事前に確認**すること
- 神社の宝物館は開館日が限られる場合があるため、特に注意が必要です
